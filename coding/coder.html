Messy phrases

Parser output often runs long. One row's agent reads by_Putin_small_war_hawks_inner_circle_national_security_adviser_Nikolai_Patrushev… — the agent is Putin; the rest is the sentence continuing. Find the head noun and code that.

The scheme

A by-phrase naming a circumstance stops at the first gate. Everything else is coded for animacy, and animacy narrows which category codes apply — three sit on either side. Valence branches from the verb, not the by-phrase.
