1 · include
Code no when the by-phrase names a condition, setting, measure or reason rather than something that brought the action about — by geography, by propaganda, by the minimum number of days. Then leave the rest blank.
2 · animacy
Go by the head noun. A country is human — a state acts through people. A nationality attached to an object does not make it human: in by Russian shells the head is shells, so nonhuman. Vehicles, substances and events named as causes are nonhuman.
3 · valence
Judge the effect on the subject, not whether the event seems good or bad in general. Violent and restrictive are separated by physical harm: seize and detain constrain, shell and kill injure. Code the reading in this row, not the verb's commonest sense elsewhere.
4 · category
Prefer the more specific code. by Russian forces is an armed body, so military_authority, not country_city — reserve country_city for phrases naming the state itself, as in by Russia.
